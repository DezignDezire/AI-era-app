# AI-era-app

Einfache Website mit:
- digitaler Uhr (rot, Wecker-Stil)
- Gästebuch (Name + Nachricht), gespeichert in Supabase

## Lokales Starten

```bash
cd /home/runner/work/AI-era-app/AI-era-app
python3 -m http.server 8000
```

Dann im Browser: `http://localhost:8000`

## Supabase einrichten

1. Projekt in Supabase erstellen.
2. SQL im Supabase SQL Editor ausführen:

```sql
create table if not exists public.guestbook_entries (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 60),
  message text not null check (char_length(message) between 1 and 400),
  created_at timestamptz not null default now()
);

alter table public.guestbook_entries enable row level security;

drop policy if exists "guestbook_select_all" on public.guestbook_entries;
create policy "guestbook_select_all"
on public.guestbook_entries
for select
to anon
using (true);

drop policy if exists "guestbook_insert_anon" on public.guestbook_entries;
create policy "guestbook_insert_anon"
on public.guestbook_entries
for insert
to anon
with check (
  char_length(name) between 1 and 60
  and char_length(message) between 1 and 400
);
```

3. In `index.html` die Platzhalter ersetzen:
   - `https://YOUR-PROJECT.supabase.co`
   - `YOUR-SUPABASE-ANON-KEY`
4. Änderungen committen/pushen. GitHub Pages deployed danach automatisch neu.
